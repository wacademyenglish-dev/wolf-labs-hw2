I Want the Chicken · The Order Pad

I want the chicken has no grammar mistake, and that’s why it survives. Table 4, 8:15 PM. Next to every choice there is a thermometer: the waiter’s mood. Every polite request warms it up; every order that sounds like a command cools it down. The order pad only fills with a polite request. At the end, the student’s first order comes back. No timer, no points.

THE GRAMMAR

I’d like / I’ll have; a request is a question: Could I have…? Can you bring…? Order for others: She’d like the fish. Complain without a fight: Sorry, I think I ordered the fish. In Portuguese “me dá a conta” is friendly; in English Give me the bill is an order, and nothing in the student’s grammar warns them. Please helps, but it doesn’t turn an order into a request (scene VI).

YOUR PICK (IX) AND THE SURPRISE QUESTION

After dinner goes wrong, three real choices: the main dish, the dessert, and a coffee the next morning. Answer first yourself, as a model. Then let your student choose, wait five seconds in silence, and ask the PUSH line (only you see it): a yes / no question. Recast quietly while they talk (I want… → I’d like…); at the end, ask them to fix one sentence themselves. About 5 minutes.

The Surprise question button (bottom right, only you see it) opens one personal question at any moment. There are three; use one when the lesson has been only exercises for a while.
