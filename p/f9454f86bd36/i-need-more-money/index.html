The Challenge · Episode 6 · I Need More Money

Episode 6. Fran is fine, but Bob and Paula need more money: chef, shop assistant, farmer, receptionist. The language is need + a thing, need to + a verb, and Do you need…? Yes, I do. (Can is already in “Seven Things”, so today the target is need.) No points, no timer.

THE TRAP
