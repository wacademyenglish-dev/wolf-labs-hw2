If So, If Not · C1 Unit 8 Lesson

PREPARE IN 1 MINUTE

What this is: a new C1 lesson on advanced ellipsis and substitution: if so, if not, if anything, if necessary, if possible, if any; I’m afraid so / not; I suppose so; not that I know of; so I hear / gather; I’d rather not; I don’t see why not.

The story: Sara (invented) books a cabin by a lake by email. The owner, Mr. Holt, answers with short, polite forms, and takes credit for his wife’s bread.

About 49 min: I · The Emails (10) · II · Long or Short? (9) · III · Bingo (8) · IV · The Jury (8) · V · Would You? (7) · VI · Quick Answers (7).

Open with: “When you book a holiday rental, what questions do you usually ask the owner?”

These short forms make the student sound fluent and polite, especially in emails. The Brazilian traps: “if yes / if no”, “I think no”, “no that I know”. The emails show them in a real booking; the bingo practises the forms; the conversation asks the student to answer short first, then add a sentence.

THE LANGUAGE OF THIS LESSON

if so / if not · I’m afraid so / not · I suppose so / I hope not / I don’t think so · not that I know of · so I hear / so I gather · if anything, if necessary, if possible, if any

THE EMAILS

Read: the student reads the text out loud. First one question before reading, then questions about the MEANING. Only then Look closer: let the student find the pattern, and tap Show the pattern to highlight it.

LONG OR SHORT?

Notice: two sentences side by side. The student explains the difference in their own words (Portuguese is fine here). Then Show answer. After the pairs come the rule cards and the traps: the student says the right form before you tap.

BINGO

A 3×3 card of quick tasks. The student picks a square and does it out loud; tap Done. Three in a line (across, down or diagonal) is a BINGO. Keep going for a second line if there is time.

WOULD YOU?

Would you rather: the student taps A or B and says why, with because. Then you answer too, and agree or disagree.

QUICK ANSWERS

Small talk: personal questions with the easier version a tap away. After each answer, wait: the student asks “And you?”.

THE MISTAKES TO LISTEN FOR

if yes, if no, I think no, no that I know, I’m afraid no, if something (for if anything). C1: one correction per answer is enough.

THE JURY (IV) AND THE SURPRISE QUESTION

In the middle of the lesson, your student is the jury after Sara’s holiday at the lake cabin: two cases (the $80 dog deposit and her 1-star review), each with three pieces of evidence. They give a verdict and defend it with the short forms (if so, if not, if anything, I’m afraid not). There is no right answer. Wait five seconds in silence, take the other side, and use the PUSH line (only you see it) to make the verdict harder. Recast mistakes quietly while they talk; at the end, ask them to fix one or two sentences themselves.

The Surprise question button (bottom right, only you see it) opens one personal question at any moment. Use it when the lesson has been only exercises for a while.

WOLF IN THIS LESSON

  • Listen: I · The Emails.
  • Focus: II · Long or Short? and III · Bingo.
  • Out loud: IV · The Jury, V · Would You? and VI · Quick Answers.
